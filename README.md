# سجل صيانة الأجهزة — وزارة الأشغال العامة

نظام ويب لتسجيل صيانة الأجهزة ومتابعتها، مع فصل كامل بين **المبنى الرئيسي** و**المركز الحكومي**.

## التشغيل

**النسخة العاملة (بيانات مشتركة بين كل المستخدمين):**
https://claude.ai/artifact/77xEND12PeCtC2XESgzGGJ

عند أول فتح تظهر شاشة **الضبط الأول** لاختيار كلمات سر الجهات.

**على GitHub Pages:** https://aed60907080-crypto.github.io/MyWork/ (البيانات تُحفظ على المتصفح نفسه فقط)

**تشغيل محلي:** افتح الملف `index.html` في المتصفح مباشرة.
في هذا الوضع تُحفظ البيانات على المتصفح نفسه فقط (localStorage) ولا تُشارَك مع الآخرين،
لأن قاعدة البيانات المشتركة متاحة داخل النسخة المنشورة على claude.ai.

## المزايا

- أوامر الصيانة: الموظف، القطاع، القسم، الطابق، الجهاز، الموديل، السيريال، التاغ، الفني، نوع الصيانة، الملاحظات
- تصوير رقم السيريال أو التاغ بالكاميرا
- مخزن قطع الغيار مع حركات الإدخال والصرف
- الفنيون وسجل كل فني
- لوحة متابعة ورسوم بيانية
- **بدل الموقع:** خريطة مواقع العمل، ومواقع الأقسام، والتقاط GPS
- التقارير الشهرية مرتّبة ومرقّمة، و**تُرسل تلقائياً إلى رئيس القسم** عند أول دخول بعد نهاية الشهر
- لوحة رئيس القسم: اعتماد الأوامر والتقارير الواردة
- صفحة مشرف الفريق (المركز الحكومي): كلمات السر، الموظفون، الأقسام، قطع الغيار، مواقع العمل

## قواعد البيانات

لكل موقع قاعدة بيانات مستقلة:

| القاعدة | المسار | ما تحويه |
|---|---|---|
| المبنى الرئيسي | `sites/MB/…` | الأوامر، قطع الغيار، حركات المخزن، التقارير، الموظفون، مواقع العمل، الصور، عدّاد الترقيم |
| المركز الحكومي | `sites/GC/…` | نفس المحتوى للمركز الحكومي |
| مشتركة | `config/…` و`technicians` | القوائم (القطاعات والأقسام…)، كلمات السر، الفنيون المسجّلون «لكلا الموقعين» |

- موظفو كل موقع (ومشرف الفريق للمركز الحكومي) لا تُفتح لهم إلا قاعدة موقعهم.
- **رئيس القسم وحده** تُفتح له القاعدتان وتُجمعان في لوحته وتقاريره.
- عند أول فتح بعد التحديث تُنقل أي بيانات قديمة من القاعدة المشتركة إلى قاعدة موقعها تلقائياً.
- في التشغيل المحلي يُحفظ كل موقع تحت مفتاح مستقل في المتصفح (`mpw.MB.*` و`mpw.GC.*`).

## الجهات والصلاحيات

| الجهة | ما تراه | ما تديره |
|---|---|---|
| المبنى الرئيسي | بيانات المبنى الرئيسي | موظفو المبنى وقطع غياره ومواقعه |
| المركز الحكومي | بيانات المركز الحكومي | الإدخال والصرف من المخزن |
| مشرف الفريق | المركز الحكومي | موظفو المركز وقطع غياره ومواقعه وكلمات سره |
| رئيس القسم | الموقعان | الاعتماد والتقارير الواردة |

## ملاحظات أمنية

- كلمات السر تُحفظ مُجزَّأة (SHA-256 مع ملح) ولا تُخزَّن نصاً صريحاً، ولا توجد في هذا المستودع.
- الصلاحيات وفصل القواعد يتمّان داخل النظام، وليسا حماية على مستوى الخادم.
- الإرسال التلقائي للتقارير يحدث عند فتح النظام بعد نهاية الشهر؛ الصفحة لا تعمل في الخلفية وهي مغلقة.
